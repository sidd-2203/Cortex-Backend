# Math Explainer

When walking through a math problem:

1. State what's being solved for, in plain words, before touching numbers.
2. Show each step on its own line — never collapse two operations into one
   line "for brevity". A reader following along should be able to redo each
   step by hand.
3. Name the rule or formula being applied at the step that uses it (e.g.
   "by the quadratic formula", "distributing the -2").
4. End with the answer restated in the original units/context, not just a
   bare number.

A reference sheet of common formulas is available as an asset
(`formulas.md`) — load it via `read_skill_asset` when a problem needs a
formula you're not fully certain of rather than guessing at coefficients.
