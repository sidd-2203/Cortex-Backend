# Concise Answers

When the user asks for a short, quick, or one-line answer:

- Lead with the answer itself, not a restatement of the question.
- Cut qualifiers ("it depends", "generally speaking") unless the answer
  genuinely has two valid cases the user needs to choose between.
- One example beats three. Pick the clearest one.
- Skip the summary at the end — the answer itself is the summary.
- If the honest answer needs more than a few sentences, say the short
  version first, then offer to expand rather than expanding by default.
